# Release Coordination

Use this rule for an authorized release. Follow
[cross-repo-changes.md](cross-repo-changes.md) for formal owner merges and Mono
gitlinks, and each owner's release runbook for package or site publication.

Record the exact compatible implementation, protocol, plugin, documentation, and
site revisions that participate in the release. Keep source merge, package
publication, deployment, real-App evidence, and user acceptance separate; report
non-applicable stages explicitly. A Mono pointer update alone proves none of
the other stages.
