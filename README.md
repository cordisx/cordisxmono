# CordisXMono

Unified CordisX workspace assembled from independently versioned repositories
under `vendors/<org>/<repo>`. Mono owns organization context and compatible
revisions; each repository owns its product code and documentation.

- [Get started and synchronize a checkout](.agents/docs/getting-started.md).
- [Find the owning repository](.agents/docs/organization-context.md#repository-ownership).
- [Register a repository or audit missing mounts](.agents/docs/repository-onboarding.md).
- [Find the applicable rules](.agents/rules/README.md).
- [Read the documentation ownership and layers](.agents/rules/documentation.md).
- [Keep files within the size limits](.agents/rules/file-size.md) and
  [split by responsibility](.agents/docs/splitting-files.md).

Agents start with [AGENTS.md](AGENTS.md).
